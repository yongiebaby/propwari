# プロップ割 工程表

日本向けのFX/CFDプロップファーム比較サイト。
差別化の軸は「ルール定義の正確さ」「合格率シミュレーター」「規約変更の追跡」「キャッシュバック」。

凡例: ✅ 完了 / 🔶 進行中 / ⬜ 未着手 / 👤 オーナー（Yuma）の作業が必要

## フェーズ0 企画 ✅
- 競合調査: 国内には比較サイトが複数ある（静的な表と記事が中心）
- 差別化の決定: 合格率シミュレーター、規約変更履歴、PipBack型のキャッシュバック

## フェーズ1 データ設計 ✅
- `supabase/schema.sql`（v2）
- 単一の情報源は `data/firms.json`。アプリはJSONかSupabaseのどちらからでも同じ形で読む

## フェーズ2 初期データ 🔶
- ✅ 7社11プラン（FTMO, The5ers, FundedNext, FundingPips, Fintokei, Fundora, Funded7）
- ✅ ルールの一次確認（2026-10-05）: FTMO、The5ers、FundedNext、FundingPips
- ⬜ ルールの一次確認: Fintokei、Fundora、Funded7（公式ヘルプのURL特定から）
- ⬜ 価格の一次確認: 全社。公式の価格表はJavaScriptで描画され、ページ取得では読めない。
  ブラウザで購入画面を開いて確認する必要あり（👤 または Claude in Chrome）
- ⬜ 追加候補: SuperFunded、E8 Markets、Alpha Capital、Blue Guardian など
- 解決済みの食い違い
  - The5ers High Stakes: 公式は日次5%・最大10%（4%・8%は別条件の情報と判断）。価格はClassic版を載せていたのでNew版に訂正
  - Fintokei 日次リセット: 2025/4/30以降はUTC 0時＝日本時間9:00（cTraderのみサーバー時間0時）。7:00説は旧ルール
- 未解決
  - FundedNext Stellar 1-Step の価格（$499.99 / $599）
  - FundedNext のサーバー時間（公式は「サーバー時間0:00」のみ。国内記事の夏6:00／冬7:00を採用中）
  - The5ers の日次リセットのタイムゾーン

## フェーズ3 MVP実装 ✅
- 比較表（口座サイズ目安・段階・プラットフォーム・日本居住者・EAで絞り込み、5種類の並べ替え）
- ファーム詳細（ルール定義、日次リセットの日本時間換算、参加費、出典、確認状況）
- 合格率シミュレーター（失格理由の内訳、1合格あたりの参加費）
- 広告表記ページ（ステマ規制対応）
- テスト17件（シミュレーション、時刻換算）

## フェーズ4 インフラ接続 🔶
- ✅ Supabaseプロジェクト（Propwari、東京リージョン）にスキーマ適用、7社11プラン投入
- ✅ セキュリティ診断の指摘ゼロ（トリガー関数のsearch_pathを固定済み）
- ✅ DBから取得した実データで変換処理をテスト（JSONと完全一致）
- ✅ ドメイン propwari.com をサイトURLに設定
- 👤 GitHubにpush → Vercelに取り込み → 環境変数3つを登録 → ドメイン接続（手順はREADME）

## フェーズ5 運用の仕組み 🔶
- ✅ 「ルール変更と訂正の記録」ページ（/changes）。当面は data/changelog.json から表示し、DB接続後は rule_changes と併用
- 当面の管理画面は Supabase Studio で代替
- 公式ルールページの差分監視（定期取得 → 変化があれば通知 → 人が確認してDB更新）
- `rule_changes` を使った「最近のルール変更」ページ
- 為替レートの自動更新

## フェーズ6 収益化・法務 ⬜
- 👤 各社アフィリエイトプログラムへの申請
- 👤 広告表記ページに運営者情報（法人名・所在地・連絡先）を記入
- 割引コードの表示UI（DBの discount_codes を使用。スキーマは対応済み）。サイト名「プロップ割」の看板になる機能なので優先度を上げる
- キャッシュバック: 設計案を作成 → 👤 景品表示法・資金移動の扱いを専門家に確認してから導入
- プライバシーポリシー、お問い合わせ

## フェーズ7 SEO・コンテンツ 🔶
- ✅ sitemap.xml、robots.txt、ページごとのcanonical、パンくずの構造化データ、OGPの基本情報
- 👤 ドメイン確定後に NEXT_PUBLIC_SITE_URL を設定（未設定だと仮URLで出力される）
- ⬜ OGP画像: 日本語フォントを同梱して next/og で生成する（開発環境から外部フォントを取得できないため後回し）
- ファーム別の解説記事、「日次DDの計算方法の違い」などの基礎解説
- シミュレーター結果の共有URL

## フェーズ8 公開 ⬜
- 一次確認が済んだファームだけ公開（未確認のものは「確認中」表示）
